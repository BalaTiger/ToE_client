## 现有实现的问题

1. 行动按钮素材约 723×152（4.76:1），CSS 使用 3.75:1 配合 `background-size:100% 100%`，导致纵向约拉高 27%。
2. 按钮文字原字号 15px，公共面板规则又覆盖为 350 字重；边框纹理的视觉重量超过文字。
3. 图标为不同字面大小的 Unicode 字符；两字与四字按钮整体居中后，图标位置和文字起点不统一。
4. 素材的平坦文字内槽约横向 13%–88%、纵向 22%–80%，现有固定 padding 没有对应这个区域。
