# 现有图片卡面的清晰度评估

2026-09-12。结论：现有素材适合直接接入手牌与放大查看，无须为清晰度重新生成卡图；但 82px 宽卡面上的规则正文太小，必须保留外置编号、牌名与放大阅读。

本次用 Pillow 只读统计了 `public/img/card/` 的实际文件。卡面由卡框图片、插画和实时 DOM 文字组成，并非包含规则文字的一张预合成图片。

| 素材 | 数量 | 实际像素尺寸 |
| --- | ---: | --- |
| 区域、检定、衍生牌卡框 | 3 | 962 × 1448 |
| 邪神牌卡框 | 1 | 964 × 1448 |
| 静态卡背 | 6 | 392 × 590 |
| 竖版插画 | 67 | 1086 × 1448 |
| 横版插画 | 19 | 1448 × 1086 |
| 竖版插画 | 7 | 1024 × 1536 |
| 竖版插画 | 4 | 1122 × 1402 |

插画合计 97 张。卡框宽度足以覆盖 300–366 CSS px、设备像素比 2 的放大显示；卡背原图为 392px 宽，在高像素密度屏幕上大幅放大时，细节上限低于卡框。以上是像素供给判断，具体纹理与文字观感仍以浏览器截图为准。

正文尺寸直接根据 [CardFaceImage.jsx](../../src/components/cards/CardFaceImage.jsx) 推导：逻辑卡面宽 392，缩放系数为 `显示宽度 / 392`；区域、检定、衍生牌规则字号初值为 16.5–22，按文本长度与框高自适应，最低 13；邪神牌初值为 17–20.5，最低 12.5。因此下表是代码允许的正文范围，并非每张牌都采用最小字号。

| 卡面显示宽度 | 区域／检定／衍生牌正文 | 邪神牌正文 | 阅读用途 |
| ---: | ---: | ---: | --- |
| 82px | 2.72–4.60px | 2.61–4.29px | 识别画面；正文不能承担阅读任务 |
| 124px | 4.11–6.96px | 3.95–6.48px | 识别卡牌；仍需要外置标签和放大 |
| 196px | 6.50–11.00px | 6.25–10.25px | 辅助查看；长文本仍偏小 |
| 300px | 9.95–16.84px | 9.57–15.69px | 放大阅读；最长文本需结合实际屏幕验收 |

表中单位是 CSS px，不包含祖先容器额外的 `zoom` 或 `transform`。设备像素比增加可改善像素精度，不会使同一 CSS 字号在版面上变大。背景风味文字另有更小的字号策略，不能用它替代规则说明。

当前实现位于 [cards/index.jsx](../../src/components/cards/index.jsx)：普通牌、神牌、黑山羊幼崽、黏液、空白区域牌与反转复原牌共用 `CardFaceImage`，保留点击、悬停、选中、禁用、高亮、倒刺归属标记及神明等级。普通手牌附有 12px 的实时编号／牌名标签，最多显示两行；标签位于卡图外，并预留 34px 空间。小牌与明确设置高度的动画／堆叠槽不追加该标签，避免叠加到其他卡上。

卡面、卡背与移动缩略图统一使用 `高度 = 宽度 × 590 / 392`；旧调用传入的矛盾高度不再压扁卡图。悬停入场的三段非等比缩放已改为等比缩放，保留原移动和交互过程。视口宽小于 640px 时，放大卡居中并关闭透视与倾斜，宽度同时受左右各 12px 留白和可用高度限制；例如 390 × 844 视口下卡宽为 366px，静止卡面不会因透视越出视口。宽屏保留原来位于中心线一侧的放大布局与透视。此调整不新增触屏手势。

保留实时文字，可以使规则、等级和编号继续跟随游戏数据，也避免将文字锁死在切图中。外置标签解决小手牌的辨识问题；卡内完整正文由放大视图承担。浏览器验收建议将同一张长描述区域牌按 82／124／196／300px 并排，对照神牌和衍生牌：小尺寸检查编号与牌名，放大尺寸检查完整规则，不以 82px 正文可读作为通过标准。

已通过 12 项卡牌 focused 检查，以及区域动画样式、个人面板两项回归；覆盖卡牌类型、等比尺寸、旧高度覆盖、状态与交互、神明等级、标签和 390 × 844／844 × 390／1440 × 900 视口边界。浏览器截图由本轮界面验收补充。
