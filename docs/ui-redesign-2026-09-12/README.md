## 制作依据

正式样板来自真实 React 组件，覆盖主界面以外的对局、系统、联机、决策、选目标、信息、教学、演出、结算和开发工具状态。完整映射见 [UI-CATALOG.md](../visual-beautification-2026-09-12/UI-CATALOG.md)。桌面截图视口为 1440×900；16 个关键状态另有 390×844、844×390 两套视口图，长结算页附底部操作区。

卡牌逻辑宽高固定为 **392:590**。布局拥挤时调整容器、列数或滚动；不得通过拉伸卡面适配。新增手牌外置标签属于卡外信息，不计入卡面高度。手机放大卡采用正面平视，避免透视裁边；桌面保留既有轻微透视。

`interface-dialogs-reference.png`、`interface-utilities-reference.png` 是 AI 方向草图，供材质与构图参考。它们的文字、规则、卡片比例不作为制作标准；正式几何以 `screens/` 和组件为准。早期比例不合格的战斗草图未接入游戏。

`panel-master.png` 为可直接切图的无字材质母版，已有 9 个独立 PNG 区块。运行 `python scripts/slice-interface-panel.py` 可重新切出边角与中心，导出两张运行时 WebP，共 **13,250 字节**。运行时以 `border-image` 九宫缩放边框，平铺中心纹理，避免整幅面板硬拉伸。按钮、弹窗和战斗板共享这套材质；卡牌继续使用已有卡框与插画。动态规则、编号、HP/SAN、按钮文字保留实时排版。

## 后续自动化复用

启动 `npm run dev`，以 `?ui-gallery=1&scene=<id>&clean=1` 打开 [场景清单](../visual-beautification-2026-09-12/ui-scenes.json) 中的状态；去掉 `clean=1` 可用底部工具栏切换。`expansion=群星呼唤` 可切换扩展主题。图库直接复用生产组件，不额外维护第二套界面。

批量截图时等待 `data-ui-gallery-scene` 挂载并核实图片载入；先固定视口再截图。内部滚动页和长页应另存底部视口，不将未渲染区域当作完整样板。素材更新后重跑切图脚本，再执行测试、lint、build，刷新资源清单。
