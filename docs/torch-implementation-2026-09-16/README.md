# 左手火把：接入方案与验收

本轮将已选定的截图方案接入 3 号「遗迹海岸」构图，四种对局主题共用。保留当前卡牌、角色面板、右侧触手和底沿，移除左下旧骷髅／蜡烛／台座。游戏规则中的角色骷髅标记不变。其他构图不增加火把，但共用新的 Gamma／遮罩层级边界。

石化配方等持续效果移到其他角色面板下方、三牌堆上方，横向居中排列，避开左侧火焰。手牌与牌堆保留原有尺寸约束。

- `public/img/ui/coastal/foreground-torch.webp`：清除旧装饰后的透明前景。仅替换原图左侧 440 像素；其余区域直接保留原素材像素。生成母版、透明底核查图及 `scripts/prepare-torch-static-assets.mjs` 留存以便复现。

- 不运行实时流体，不逐帧生图；离线 EXR/VDB 缓存不进入网页资源或版本库。运行时使用 RGBA8 色彩图集，解码原始像素约 24 MiB。静态图用于加载期间和失败回退。

## 层级与 Gamma

同一 document（手机为现有横屏 iframe）内建立三个视口兄弟层：

1. `scene`：场景、手与火把、普通 UI 和普通飞牌；保留现有 Gamma 参数。
2. `flame`：透明火焰画布；无祖先 Gamma 滤镜，鼠标／触摸完全穿透。
3. `overlay`：全屏暗幕、弹窗、身份／教学、翻牌揭示及停帧决策；继续跟随 Gamma，并覆盖火焰。

Gamma=1 使用 `filter:none`。不分别给每张卡牌加滤镜。所有根层不做缩放或运镜，避免 fixed 元素改参照系。普通飞牌留在 scene，直到原翻牌进入全屏揭示段才提升至 overlay，保留阶段管理与原动画完成回调。

`CoastalTorch` 从实际火把锚点取得位置，将火焰映射到相同视口，并裁在对局安全区域内。静止时仅监听 resize／scroll；有震屏时限时跟踪位置，不常驻每帧测量布局。画布与静态火把不接收点击。

拆分合成顺序后，半透明区域不承诺与旧 body 滤镜逐像素一致。当前维持原遮罩与 Gamma 参数；火焰在有 overlay 内容时额外减至 22% 强度，避免穿过暗幕抢焦点，独立于 Gamma。

## 手机与 HDR

- 默认每秒 24 次绘制；遮罩内容出现时降至 12 次。渲染与 React 状态更新分离。
- 实际画布最大 256×512，计算像素时纳入 `--toe-mobile-screen-scale`，避免横屏 iframe 逻辑尺寸叠加高 DPR 导致过采样。
- 后台、单人暂停、不可见或完全遮住时停止更新；减少动态效果偏好保留静止火焰。
- 不做全屏 HDR 缓冲或实时大范围模糊。泛光随素材烘焙。
- SDR 为 Canvas2D；浏览器具备 WebGPU、HDR 能力且初始化成功时使用 `rgba16float`、`toneMapping:extended`。着色器在线性光空间调节发光，再编码为扩展 sRGB 并预乘 alpha。初始化／设备丢失失败回退 SDR。
- 运行图集是色调映射后的 8 位图，HDR 增益 3 是艺术调校，不宣称从图集还原了 EXR 原始辐射值。物理屏幕 HDR 亮度与手机持续温升仍需实际设备验收，API 成功不等于已完成这些验收。
