## 提取约束

- 沿用既有 `scripts/extract-coastal-assets.mjs` 的确定性棋盘底识别、边缘去污染与 alpha 裁切流程，不重绘原素材。
- 日志页为浅色旧纸。保留其封闭纸面，只清除与画布外边缘连通的底色，避免把纸面当成封闭棋盘孔。
- 本轮三张母图均经检查为 RGB、没有原生 alpha；棋盘格是图像像素。脚本拒绝将另一个带原生 alpha 的母图展平后处理。
- 回合栏含圆槽时整幅保持原比例；单独按钮以透明补边形成正方形，不做横纵独立缩放。
- 左书脊、扣带与圆铆钉属于日志素材；右下触手继续由现有前景绘制，不重复烘焙进日志图。
- 九宫格不得穿过圆形铆钉；各角块使用同一个缩放比例。直边与纸张区域可重复填充。

## 复现与检查

在前端仓库根目录运行：

```sh
node scripts/extract-coastal-corner-b-assets.mjs
```

脚本优先读取本目录母图，缺失时才从生成目录复制；首个命令行参数可指定生成目录。Sharp 沿用本机运行时，可由 `SHARP_MODULE` 指定其模块路径。此目录内的脚本文件是生产快照，运行入口为仓库 `scripts/` 文件。

`production-assets.json` 保存来源、输入输出尺寸、是否含 alpha、裁切边界、透明补边、去底参数和 SHA-256。每次执行检查三张输出四角透明、圆底为正方形，并采样验证日志正文安全区域保持不透明。`production-assets-dark-preview.png` 已目视检查，无残留棋盘格、白边或误透明的纸面。

完整母图、生成提示词（由主任务记录）、脚本快照、布局坐标和预览均保存在本目录。所有新资源采用 `corner-b-*` 命名；被否决素材保持不变。

## 接入范围

原素材的测量与建议安全区见 `asset-layout-guide.json`，均相对最终 WebP；游戏实际坐标以下方实装说明及 `COASTAL_CORNER` 为准。

- 回合栏黑色内区约 x310～2020、y144～424。文字安全区建议 x340～1150、y160～407；两个圆按钮中心可落在 x1440 和 x1810、共同 y285，按钮原坐标直径约290，随整幅素材等比换算。
- 日志正文安全框建议 x255～860、y170～1175；左内缩较多是为了避开书脊与中段扣带。内容区可独立滚动。
- 新日志的圆铆钉并非只在四角，中间扣带也有圆形。优先整幅等比显示，例如宽235时高339.1；通过前景遮挡适应构图。若采用九宫格，纵向边片不能拉伸，应选择不会切中圆铆钉的位置并重复填充。
- 圆控制底图保持1:1，两按钮共用同一尺寸与底图，图标单独绘制。内部图标安全直径约790像素，即整体宽度约71%。

## 实装说明

[`COASTAL_CORNER`](../../src/components/battle/coastalGeometry.js) 是右上角共享逻辑坐标来源。回合栏宽292、top −3、right −22，按2144:590原比例显示，允许外缘超出画面。`BattleScreen` 使用同一组坐标与安全视口倍率定位固定系统控件，不能再分别写两套屏幕百分比。

两个按钮共用 `corner-b-control.webp`，逻辑尺寸均为54×54，间距8；各自叠加30×30的独立 SVG 图标 `corner-b-pause.svg`、`corner-b-settings.svg`，不是用字符替代图标。它们随同一构图倍率等比缩放。联机对局仅显示设置，单机才显示暂停；身份选择和身份揭示期间继续隐藏两入口。系统控件与菜单仍处于全屏遮罩之下，退出沿用二次确认。

日志底图固定逻辑宽224，top92、right −12，以975:1407完整等比绘制，原生书页高度 `bookHeight = 224 / (975 / 1407)`，约323.25。当前实现不使用九宫格，也不缩窄书本或拉伸书脊。内容容器高度为 `min(bookHeight, controlsTop - logTop - 4)`，棋盘最小高度保证其至少160。繁衍等额外操作出现时缩短滚动区域，不缩小字体或挤窄正文。

内容 padding 为：顶部 `bookHeight × 0.12`、左侧书宽的27%、右侧11.8%、底部 `max(16, logHeight - bookHeight × 0.78)`。标题固定在正文滚动区之外，字号17；正文13.5，使用深褐色墨迹。`logRef` 保留在真正滚动的 `[data-log-panel]` 上，原日志追踪与自动滚动继续生效。

书页背景与文字分层：书页装饰层 `z-index:-2`，既有触手/骷髅前景 `-1`，日志内容层 `10`。书页底部只显示至 `logHeight + 18`，余下部分裁在提示栏和触手后面，素材本身尺寸保持不变。运行时纸页使用 `brightness(.78) saturate(.7)`，生产图没有为适配界面再调色。

系统控件的固定根节点与展开菜单不加震屏 transform，也不进入棋盘 zoom 或背景滤镜容器。仅触发按钮组外侧的、未 zoom 的 `BattleSceneContent` 外壳接收与棋盘相同的 shake；按钮组自身再使用构图倍率，避免双重缩放震动距离。该结构使按钮与回合栏同步震动，同时保持 fixed 坐标和菜单位置稳定。
