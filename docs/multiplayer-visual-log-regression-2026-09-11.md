# 联机视觉与即时日志回归记录（2026-09-11）

## 环境与判定原则

- 前端：本地 Vite，`http://127.0.0.1:5173`（含 `localhost:5173` 入口），开启 `toeTraceAnim=1`。
- 后端：`ToE_server`，`http://127.0.0.1:3002`，仅监听本机；使用真实 Socket.io 房间与匿名身份。
- 三个真实浏览器客户端进入同一房间，分别观察行动者、目标、第三人；通过界面操作、动画 trace 和可见日志比对。
- 规则层产生视觉事件，即时日志随事件播放。最终结算日志保持独立；没有使用最终日志补播或反推视觉事件。
- 与单人体验对齐的标准是规则结果、动作顺序、消息归属与次数一致，不要求各浏览器动画在同一毫秒开始。

## 发现与修复

| 问题 | 根因与改动 | 验证边界 |
| --- | --- | --- |
| 黑夜掉包远端漏骰子、漏日志 | 目标阶段只在本端播放；暗抽阶段禁止普通广播，最终广播又裁掉已消费事件。`setGsWithApophisTargetAnim` 改为消费前广播同一目标事务 | 第三场掷出2，目标由莉莉偏移到贝拉，米娅SAN 9→8；三端各一次骰子和日志，随后掉包与两次飞牌没有重播骰子。自动测试另覆盖低SAN检定后牌堆/弃牌堆结果 |
| 消息归属与属性权限误报 | 精确队列的 `turnOwner` 未随座位旋转；旋转时还为原本缺失的可选字段创建了 `undefined` 属性，改变属性存在性判断 | 修复 `rotateState.js`；覆盖座位往返、缺失字段与实际掉包消息 |
| 真人追捕亮牌被服务端拒收 | 服务端只允许当前回合者发状态，拒绝上一权威状态指定的被追捕者 | 服务端按上一快照的决策阶段、指定座位授权；追捕另校验同回合、提示、目标和持有牌。第二场浏览器已通过 |
| 手牌信仰、弃牌、蛊惑主语错误 | 共享消息使用本地“你”；目标名字转换后出现“你对你” | 生产者写入真实角色名，展示时转换本端名字；保留目标代词含义，不全局替换“你” |
| 蛊惑 TSG 强制改信缺两句 | 遭遇消息未绑定事件；信仰事件错误选中旧神退出罚 SAN 句 | 蛊惑事件显式携带 `encounterMsgs`；信仰规则显式传 `statusMsg`。实际处理函数验证赠予、遭遇、改信处罚、新信仰四句完整且各一次，SAN 10→8 |
| SHU 授予缺视觉事件 | 目标选择后的授予未完整进入事件回放链路 | 第三场米娅授予贝拉幼仔：三端各一次飞牌和授予日志；目标手牌由4变5，下一回合先处理幼仔HP/SAN，再摸牌 |
| 强制地震重复消息 | 强制摸牌缺少明确的翻牌消息归属，使效果消息重复进入翻牌与地震事件 | 第二场浏览器复现；修复后用真实回合规则与三视角队列回归验证，第三场未再次随机摸到地震，不计作修复后浏览器覆盖 |
| TSG 超时指令跨端泄漏 | `_mpAutoDiscard` 是本地命令，结算后仍被广播；其他端重复执行。现在由弃牌规则消费后清除，接收端仅响应本地合法弃牌阶段 | 实际 effect→弃牌→TSG→下一回合→两名远端回放通过；第三场第一次真实超时弃牌已正常推进，无其他端误弃牌 |
| 后续超限不再计时 | `_mpEndTurnDiscardResolved` 残留；进入新的弃牌阶段时重置 | 第三场复现后，莉莉再次超限恢复15秒计时并自动弃置绳索，只推进一次米娅回合；规则与计时归属回归通过 |
| 退出后的迟到动画回调 | 退出未清待提交状态、回调和播放生命周期。三个退出入口现在复用队列重置并清回合末游标 | 第三场贝拉在幼仔/断绳/摸牌队列播放期间确认退出，后续其他端继续到下一回合，贝拉仍保持菜单；实际退出 handler 与 hook 迟到回调回归通过 |
| 两人一绳选目标卡住 | 手写飞牌步骤没有绑定规则生成的 CARD_MOVE；旧事件数组还覆盖了新黑夜事件 | 直接编译规则事件。第三场现场恢复：三端各一次骰子（6）→架绳动画，日志与当前断绳3HP、到期4HP规则一致。自动测试另覆盖黑夜偏移/检定和休息续摸 |
| 幼仔触发断绳漏反应日志 | 幼仔结算忽略 submitLossEvents 返回的完整事件，按最终数值重建时丢失断绳消息 | 改为保留完整规则事件和现场消息。新增单人/三端回放回归：贝拉HP 9→8→5、莉莉10→7，断绳句仅一次且在摸牌前；此最后补丁未重新开浏览器随机场次 |
