各素材提供 `-1x.webp`、`-2x.webp`，由 CSS `image-set()` 根据像素密度选取。先按面板逻辑宽度平滑缩图，避免高频纹理在缩小的舞台中产生颗粒；原图保留以便重新输出更大尺寸。背景保持原比例，通过 `cover` 裁切；全部文字、图标和边框继续由现有界面独立渲染。

处理脚本：`node scripts/prepare-start-semantic-assets.mjs`，复用现有 Sharp 工具（可通过 `SHARP_MODULE` 指定）。

按钮与静态信息面板区分：静态边框亮度降至1.15；按钮边框1.75，增加顶部内高光、5px青铜/紫灰底沿和落影。悬停或键盘聚焦上抬2px并略亮，按下向下3px、厚度收缩。禁用状态不响应位移；减少动态效果偏好取消位移和过渡，保留颜色、边缘反馈。无持续闪烁或呼吸动画。

固定舞台、面板尺寸、文字比例、介绍两行排版、四角控件锚点保持原规则。面板仍为415×98、规则区510×312、主按钮385×112。

验收：主界面16项几何/移动横屏测试通过；浏览器核对1280×720、1600×1000和617×1009，无横纵溢出，介绍保持两行。键盘Tab可依次聚焦两个入口，并得到抬升、提亮和清晰焦点轮廓。Lint与生产构建通过。
