# 共享桌面透视与牌堆厚度

三个牌堆共用45°桌面与一个透视中心。普通牌堆、检定牌堆整齐叠成方柱，弃牌堆保留错位旋转；真实纸边厚度随牌数增长，上限18个布局像素。沿用现有卡背与原始392:590卡面，没有拉伸或新增素材。

飞牌使用实际顶牌的共享投影作为起终点，中段继续按远近变化缩放和沿Z轴移动。角色面板组与牌堆组共用实测中心线，角色位置、持续效果列宽度均保留。

验收：

- 1200×750：两组中心均为603px；普通牌堆飞出首帧与实际顶牌的包围盒差异小于0.005px。
- 1920×1080：两组中心误差约0.008px；弃牌飞行末帧与实际顶牌误差小于0.015px。
- 普通/检定牌层XY相同、Z逐层增加；弃牌层仍有不同XY及旋转。
- 持续效果场景保留108px文字列，实际牌面与效果区间距约7px，没有重叠。
- 抽查经典布局，共享桌面、纸层与平直计数均正常。
- 完整Vitest：150文件、1853项通过；随后中心线调整的聚焦测试与Lint通过，生产构建通过。构建保留既有大包提示。

`coastal-table-1200x750.png` 为真实组件的固定场景截图；`coastal-effects-1200x750.png` 为持续效果与照亮牌场景。测量记录见 `measurements.json`。
