# 主界面固定构图 · 2026-09-15

按本轮确认的参考图重排主界面。标题、三职业与规则区、主按钮、下方辅助按钮使用同一个 **1490×1056** 设计舞台；窗口变化时整体居中、等比缩放，取消原有宽度插值和改变排版的媒体断点。

## 构图与缩放

[`startScreenGeometry.js`](../../src/components/start/startScreenGeometry.js) 导出设计宽高和 `getStartScreenScale(vw, vh)`，倍率为 `min(vw / 1490, vh / 1056)`；缺失、非正或非有限的视口输入按对应设计尺寸回退。组件 [`StartScreen.jsx`](../../src/components/start/StartScreen.jsx) 与 [`start-screen.css`](../../src/components/start/start-screen.css) 只对舞台整体缩放，标题、图标、框图、文字的相对尺寸始终一致。

| 区域 | 设计坐标与尺寸 |
| --- | --- |
| 标题 | 左465、上105、宽560，保持图片原比例 |
| 背景介绍 | 左265、上370、宽960，字号20、行高34 |
| 职业与规则区 | 左265、上460、960×312；两列415/510，间隔35 |
| 三职业面板 | 每条98高，间隔9；图标62×62 |
| 主操作区 | 左295、上804、900×130；按钮385×112，字号36 |
| 辅助按钮 | 设计舞台左右各留20、下留38；按钮260×57.37 |

介绍文字完整保留为两行，每行 `white-space: nowrap`，不会因窗口缩放增至三行；超宽窗口也继续使用该两行版本。主界面禁止浏览器单独进行文字尺寸调整。所有装饰中带圆形的部分继续保持原图长宽比。

现有 `public/img/bg/bg_main.webp` 作为独立全窗口背景，使用 `background-size: cover` 与 `background-position: center top`。它不属于缩放舞台，窗口额外空间显示背景；主界面内容不会因空间变宽而重新分配比例。

## 弹窗与横屏集成

App 将同一个倍率传给 Debug 按钮组和视听设置触发器，使它们与设计舞台同步定位。只有设置触发器缩放，设置面板保留视口布局，并扣除顶部锚点、触发器高度及底部留白来限制最大高度。

关于作者、版本更新计划、联机选项、断线遮罩和 toast 均位于缩放舞台外，保留 fixed 定位与原交互。移动端仍使用 `mobileLandscape.js` 的持久横屏 iframe；菜单读取 iframe 内逻辑宽高，宿主翻转只改变画面朝向，不替换 iframe 或重建 App。

对局的 `UiAppearanceProvider` 与界面构图切换接口保持不变。主界面设计、对局构图和 DLC 主题是独立概念，本轮不改变拓展包资源选择、规则或游戏状态。

四张无字底图使用内置 **imagegen** 生成。完整提示词、参考文件、生成源图位置和处理方式保存在 [`generation.json`](generation.json)。生产素材按原比例缩放为 WebP，由 CSS `cover` 裁切显示区域，不变形。

| 素材 | 用途 |

边框复用 `role-panel-9slice.webp`，真实裁出 `frame-tl/tr/bl/br.webp` 四角及 `frame-top/bottom/left/right.webp` 四条窄边，共八张。四角保留40×40像素，边条只取14像素厚的外框，排除源图内部黑色留白；由多层背景组合在独立场景底图上，避免面板内侧出现黑带。原图与全部裁切坐标见 [`frame-crops.json`](frame-crops.json)。

## 验收记录

[`measurements.json`](measurements.json) 已记录1491×1055、1600×1000、1900×1000、2560×720、900×474、1024×768、1440×900七种视口。各尺寸均保持两行介绍、无文字溢出，页面尺寸与视口一致；逆向除以统一倍率后的标题、信息区、主操作区、辅助区坐标保持一致。

标题宽与主按钮宽之比约为1.454545，主按钮字号与高度之比为0.321429，职业图标长宽比为1，均不随窗口改变。几何 helper 的9项测试覆盖画布完整显示、等高宽屏仅增加背景空间、非法尺寸回退，以及手机 iframe 翻转后的物理尺寸保持。
