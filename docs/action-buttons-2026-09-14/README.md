# 回合主操作按钮调整 · 2026-09-14

技能、休息改为手牌区的主要操作：桌面紧邻手牌数量，结束回合独立靠右。技能使用金铜铭牌轮廓，休息使用绿色胶囊轮廓；放大身份/心形图标，延续主界面的暗色纹理和金属边框。

- 桌面按钮为 132 × 44 CSS 像素，主文字为 15px；补偿棋盘整体缩放，保证实际点击高度为 44px。
- 手机竖屏将技能、休息放在独立的一行，等宽展开；手牌数量与结束回合放在上一行。
- 手机横屏将手牌与操作组并排，主按钮最小宽度为 110px。手牌溢出时横向滚动，保留顶部信仰提示空间。卡牌长宽比保持 392:590。
- 禁用按钮保留轮廓与文字，以暗灰材质和状态副标题区分；技能、休息原有可用条件、回调与教程定位保持不变。
