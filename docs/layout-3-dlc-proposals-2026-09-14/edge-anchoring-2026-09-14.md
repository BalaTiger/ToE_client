# 3号布局：与画面边缘融合

按最初的3号布局参考，强化桌面三处装饰出框。沿用现有透明素材，仅修改 `coastal-layout.css` 和 `BattleScreen.jsx` 的位置与内容留白。

- 玩家框左移14、上移18设计像素，外圈尖角融入左上画面边界；头像、姓名与HP/SAN使用独立内边距，信仰布旗保持原水平位置。
- 其他角色容器上移12设计像素，统一上框边进入屏幕外；顶部内容留白增加到22像素。当前回合标记放到面板下缘，保持完整可见，原当前角色置顶机制不变。
- 星盘上移44、右移36设计像素，整体300×203；顶部与右侧外环越过画面边界。回合文字重新对齐底图内部，暂停和设置按钮留在屏内。
- 负向位移使用实际 `top`，角色区下缘仍被已有共同几何测量读取，因此牌堆与手牌净空自动随新位置调整。未增加整张桌面的裁切层。
- 手机和窄屏继续使用原安全边距及滚动布局，不应用桌面负向偏移。

验证：4个聚焦测试文件共39项通过；ESLint及生产构建通过。构建仍保留已有大chunk提示；资源清单仅生成时间变化已还原，没有新增素材。

浏览器检查了1600×900、2548×1303、1280×720（11名对手）与390×844。姓名、HP/SAN、回合文字均在屏内；系统按钮维持44×44px。拥挤场景的当前回合标记完整可见，手机没有新增横向溢出。
