# 主界面横向适配

原主界面只根据宽度增大尺寸：1440×900 实测页面高 1056px，主操作按钮下缘到 946px，页脚按钮下缘到 1032px。标题区固定最小高度和顶部留白、职业与规则上下堆叠、过宽的主按钮共同占用了过多高度。页脚还存在实际按钮约 78px、容器却只有 60px 的差异。

900px 及以上窗口改为职业区与规则区同排，使用原生 CSS Grid。职业面板约从 272×200 收为 218×160；主操作按钮从 377×126 收为 300×101，低窗口进一步收宽。原字号、职业图标和各底图比例保持不变；常规桌面职业图标 42px、职业名称 18px、主按钮文字 26px。标题回收无内容留白，页脚改为正常文档流按真实高度占位。

较低窗口让引导文案使用更宽的行宽；高度不超过 600px 时，关于作者与更新计划纵向放在主操作旁，利用横向空余。小于 900px 的竖向布局保留原有堆叠方式。没有缩放整页、裁掉内容或引入布局库。

Debug 开关与 Debug 设置改为同一固定 flex 工具栏，真实按钮盒间隔 20px。600px 及以下纵向排列，避开顶中视听入口；设置弹层保持在工具栏之外。

## 收敛横向构图

针对信息行过宽的问题，桌面最大宽度从 1120px 收至 880px；职业／规则分栏为 3:2，间隔 12px。职业间隔 8px，单块约 168×124px，内边距 10px；规则区约 347px 宽。各图标、字体和底图比例保持原值，职业文字容器限制在框内。信息行与约 700px 的入口区形成较缓的宽度过渡。

低窗口因引言换行会增加高度，将已有辅助入口侧置断点由 600px 扩至 680px，继续完整保留规则与操作。验证 900×474、1024×540、1140×600、1160×611、1200×632、1280×674、1368×720、1440×900，均无页面滚动及职业／页脚文字裁切；浏览器无错误。182 项现有测试、lint 和构建通过。

## 专用九宫格底图与内容留白

使用内置图像生成工具，参考现有主界面做旧金属材质生成专用横条。三职业共用 `public/img/ui/start/role-panel-9slice.webp`（768×256），CSS `border-image: … 40 / 12px` 固定四角、拉伸直边；不用 `fill`，中心改用同图裁出的 `role-panel-surface.webp`（256×128）重复铺设，叠加各职业绿、红、紫底色。没有拉伸整张框图，也不需要三套重复素材。完整提示词和裁切坐标见 [生成记录](role-panel-generation.json)。

职业列按现有字号响应区间从176px增至224px；常规桌面由280px收窄至224px，图标与文字间隔由14px改为10px。上下内边距由6px增至11px，名称行高明确为1.25，两行间距3px，保留原字体大小及图标大小。实际文字容器距外缘约11–14px，内框只占数个像素；最长目标仍有至少34px右侧余量。职业与规则整行最多664px宽，避免规则区域反向膨胀。

小横屏将辅助入口列调整为210–260px，顶部留白收4px，补回新增面板留白所用高度。900×474、1024×540、1200×632、1280×800、1368×720、1440×900、1920×1080及390×844验证无页面滚动、职业目标或页脚文字裁切，所有职业图标保持正方形。182项现有测试、lint、生产构建通过；新素材对应资源清单版本 `c8dd3e6ef6cfde9a`。

## 消除内侧黑边、辅助入口移至角落、手机固定横屏

九宫格改为 `40 fill / 12px`，统一填充边框内侧与中央区域，再用 screen 混合叠加职业底色，消除原裁切中心与边框之间的黑色带。原独立底纹文件保留，但当前面板不再引用。

横屏菜单的关于作者、版本更新计划分别固定在左下、右下角，宽170–210px，字体10–12px，缩放保持底图比例。主入口仍居中，低窗口为角落留出横向空间。900×474、1024×540、1200×632、1368×720、1440×900均无滚屏、页脚文字裁切或按钮重叠。

移动端改为持续存在的横屏 iframe，900×600最小逻辑视口按比例缩放；手机翻转仅调整外层朝向，内页尺寸和游戏状态不变。验证390×844和375×667及其横向尺寸，菜单、弹窗、对局均可显示，旋转后的点击可继续处理区域牌。新增几何和frame保留测试，全量146文件／1795测试、lint、构建通过。
