## 提取与复现

在前端仓库根目录运行：

```sh
node scripts/extract-coastal-corner-assets.mjs
```

脚本优先使用本目录已存档母图；缺失时才从默认生成目录复制。可用首个命令行参数指定另一个生成目录；可通过 `SHARP_MODULE` 指定 Sharp 模块路径。目录内同名脚本是生产时的快照，实际运行入口仍为仓库 `scripts/` 文件。

处理复用 `scripts/extract-coastal-assets.mjs` 的确定性流程：检测中性棋盘格，清除连通的外部底色与封闭棋盘孔，保留最大连通主体，去除一像素边缘白底污染，按实际 alpha 边界外加两像素透明余量裁切。常规底色最小通道阈值为 130；本轮铭牌的棋盘暗格较暗，单独采用 110，避免边缘残留棋盘点。未重绘、调色或重采样素材；输出 WebP 的质量为 94、alphaQuality 为 100。

圆底座按裁出的 1249 × 1240 画布上补 4、下补 5 像素，得到正方形。只添加透明像素，不改变圆形图案的横纵比例。

`production-assets.json` 记录来源 SHA-256、原始尺寸、实际 alpha 边界、裁切矩形、透明补边和输出 SHA-256。`production-assets-dark-preview.png` 用于检查底色残留和边缘。

## 接入定位

精确坐标见 `asset-layout-guide.json`，均相对最终 WebP，属于绘制内容的安全区建议。

- 铭牌竖向分隔梁位于 x≈1250，即宽度的 58.113%。左右两格正文的共同纵向中心为 y≈255，即高度的 48.85%。铭牌应按 2151:522 等比显示，不沿用旧星盘文字框的百分比。
- 日志上方细线位于 y≈193；正文安全内缩约左 17.1%、右 9.2%、上 16.8%、下 6.7%。左侧是书脊，不应放正文。
- 日志使用九宫格时，`240 120 120 180` 的切片线已完整保留角上的圆铆钉；若需要完整保护左下曲面角饰，可改成 `240 120 190 180`。边框显示厚度必须使用同一个缩放系数，例如 0.2 倍对应 `48px 24px 38px 36px`，圆铆钉才不会变椭圆。纵向书脊建议 repeat，避免把其中的圆铆钉纵向拉长。
- 九宫格正文 padding 应按所选边框厚度重新计算，不应机械沿用整幅素材百分比。
- 圆底座的 width 与 height 必须相等，图像使用 contain；内部图标安全直径约为输出宽度的 69%。
