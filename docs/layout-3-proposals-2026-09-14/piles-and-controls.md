## 控制入口建议
| 功能 | 位置 | 交互 |
| --- | --- | --- |
| 暂停 | 右上星盘下沿小刻铜按钮 | 单机直接暂停；教学禁用；联机和观战不提供暂停 |
| 菜单 | 暂停旁的小齿轮 | 点击展开一层浮层，点击外部或关闭按钮收起 |
| 亮度（Gamma）、音乐、音效 | 菜单内部 | 三个滑条直接调整，无需另进设置页 |
| 界面构图 | 同一菜单 | 保留当前整体 UI appearance 切换入口，与拓展包主题独立 |
| 返回主界面 / 退出对局 | 菜单底部独立项 | 单机显示返回主界面，联机/观战显示退出对局；退出确认见下文 |

一层浮层足够，无需多级设置页面。展开层可临时遮挡日志，但应处于角色面板和星盘控制下方、主操作提示上方，保留手牌、牌堆和主操作按钮可见。窄屏用同一面板适配可视区域，而非增加导航层级。

菜单不是暂停：打开视听设置时，维持当前游戏继续推进的行为。单机暂停仍由独立入口触发；暂停层保留继续游戏和返回主界面。

## 现有行为核对
- GammaSlider 当前包含亮度、音乐、音效、界面构图，悬停展开/点击固定，且不暂停。此方案建议改为明确点击展开，避免指针经过星盘时误开菜单。
- BattleHeader 当前仅单机提供暂停，教学禁用；联机与观战没有暂停入口。
- 联机退出已有确认：进行中“对局还在进行中，是否退出对局并离开房间？”；观战“你将离开游戏房间，确定要退出吗？”。继续复用。
- 单机返回主界面当前直接清局。用户已同意新增一次退出确认，待效果图完成后再实施；当前尚未应用。确认属于退出操作自身的保护，不是另一层设置导航。

实际接入可继续复用现有 GammaSlider 的偏好与音量处理、BattleHeader 的模式分支及暂停/退出回调。菜单保持在 Gamma 滤镜外，避免亮度过低影响设置本身可用性。无需增加 UI 框架。
