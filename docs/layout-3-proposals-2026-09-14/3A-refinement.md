## 设计调整
1. 右栏的回合、日志、按钮分别定位。以 1672px 宽参考画布规划，左边界目标约为 1215px / 1435px / 1305px，实际效果图仍以视觉关系为准。关键是回合最左、日志最右、按钮居中，不共用统一左边界。
2. 顶部四个其他角色面板适当压缩横向宽度，为回合牌让位。正式接入时继续使用一致形状与实时条形数值；人数扩展规则另按已有框架处理。
3. 金属用较细的暗铜骨架、不连续的磨损反光和局部暗缝。按钮保留弱色差，主要依靠可读文字、尺寸和轮廓体现操作地位；悬停/可执行/禁用状态需独立设计，不能让全部按钮近似禁用。
4. 提示放在按钮上方内缩窄布签，日志使用后退的暗布底；边界可以起伏，但动态文字保留稳定的可读区域。
5. 人物、图标与衍生牌的正式素材应进一步消除光滑塑像和粗剪影效果。特别是衍生牌必须复用游戏真实卡面，效果图的生成缩略牌不能直接作为游戏素材。

## 制作边界
玩家手牌、衍生牌、卡背仍直接采用游戏素材，锁定 392:590。人物、数值、条和文字由真实组件提供。生成图作为材质和构图依据，动态内容不切成位图。

后续制作可分别导出回合框、日志布料、按钮底图、提示布签；各自使用透明边缘与独立的定位参数，避免切成等宽的一张右栏大图。装饰外缘与交互内容区分开定位。无需新增 UI 框架。
