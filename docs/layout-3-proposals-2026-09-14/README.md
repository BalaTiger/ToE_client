共同设计约束：
- 左上主角 HP/SAN 为条形，SAN 保留固定 6 刻度。
- 左侧旗帜布料显示当前信仰、效果和其他 tag。
- 顶部其他角色使用一致矩形面板，容纳 HP/SAN 条、正面衍生牌和其他背面手牌。
- 回合牌下方显示日志；中央海面保持通透。
- 深色卡面沿用实际游戏的素材结构，正式接入时直接复用现有 CardFaceImage，保持 392:590 比例、相邻固定重叠、局部悬停抬升。
- 掉包为样例角色当前技能名；繁衍按钮为样例手牌未持有黑山羊幼仔时的不可用状态。正式交互条件沿用游戏规则。
- 图像生成的字形、卡牌编号、数值和进度条仅用于呈现信息密度；生产版由现有文字、状态和卡面组件提供，不从效果图截取动态内容。

选定后可拆分的静态素材：海岸场景底图，主角信息框，通用旗帜布料，其他角色通用框，回合框/仪盘装饰，日志底托，通用按钮底图及状态，提示底托，通用手牌计数徽章。卡牌本身不新增一套美术设计。

选定后通过已有 UI appearance 接口新增 3 号构图，保持与拓展包主题独立。此阶段不更改默认构图、不接入运行时素材。
