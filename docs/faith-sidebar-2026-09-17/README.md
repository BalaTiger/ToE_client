# 玩家信仰区扩容 · 2026-09-17

## 实施

- 3号布局的左下三牌堆余量区域以左下角为锚点等比缩至80%。侧栏按计数框实测高度自动向下延伸，继续保留14px逻辑间距。
- 移除可见的“当前信仰”标题，保留神名、神力名和等级。无信仰时保留“尚未信仰邪神”。
- 正文由12px/1.55行高调为10.5px/1.45行高；通过棋盘与移动宿主缩放变量保底约11px实际屏幕字号，不截断文案。
- 原生滚动区域按溢出方向显示上下SVG箭头，支持点击翻页、触摸滚动与键盘。箭头不占排版高度，避免出现/隐藏导致循环溢出。
- 神名或等级变化时回到顶部；普通状态tag更新不打断阅读位置。
- 未改变火把、手牌、三个实际牌堆、其他角色及日志的位置。现有端帽、圆框与暖光素材维持原比例。
