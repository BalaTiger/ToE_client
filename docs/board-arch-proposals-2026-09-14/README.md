## 已选方向与精修

用户指出初稿把部分角色面板斜切或弯曲，不利于素材复用；面板形状必须一致，上缘可有统一修饰。用户同时否定自身/日志简单向下鼓出的圆弧底，随后认可该批最后一张 [B · 七角色图](B-seven-players-selected-direction.png) 的方向。

本轮 [B 精修图](B-refined-seven-players.png) 沿用该构图：

- 七个其他角色复用同形矩形框，只允许整体平移与小角度旋转，不允许透视斜切、剪切或弯曲素材。所有面板采用相同角件和顶部小饰件；回合高亮只改变描边、状态与阴影，不改变面板轮廓。
- 仍为单排拱形。贝拉（从左第二位）处于回合中，面板覆盖左右邻居，以展示前后层级，座次不变。姓名、HP/SAN 与公开状态保持可读；未公开的角色身份和普通手牌不提前展示。
- 自身和日志保留独立切角轮廓，下缘增加双层铜压边、浅刻扇纹和小型角件，使用不透明实底与短阴影，不渐隐、不向下鼓弧，也不连接为横贯画面的分界。
- 保留居中提示、简单手牌弧线、独立下沉的通用手牌计数和可替换主题浮雕。

上述 PNG 是设计效果图；顶部“已接入游戏”中的截图来自运行时。主手牌使用真实卡面与既有 392:590 比例、20% 重叠，不从生成图中提取卡牌正文作为游戏素材。角色框已制作成一套可复用装饰组件，而非对每个倾斜面板分别切图。
