# 静态打湿材质对照

静态目标确认后已接入正式游戏：水膜遮罩只控制原干图与提取湿图的混合，不再自己绘制黑膜、噪波反光或水珠。

## 实际游戏来源

在正式单人游戏界面选择三号布局、群星呼唤、追猎者开局，在探索运镜与浪花同时播放时截取。不是 VisualGallery 合成场景。

- [实际游戏截图](game-splash-1.png)：截图前采样，主浪 opacity 0.634、火把水膜 0.794、面板水膜 0.790。
- [首版完整打湿效果图](wet-material-target.png)：内置 image_gen，根据该截图编辑。用户已认可其中火把和手部材质；面板部分不采用。
- [光滑金属面板重制](panel-smooth-metal-wet.png)：内置 image_gen，根据用户面板局部截图单独重制；用户已确认基本光滑的金属板材质。仅作为材质目标，不作为带文字完整底图使用。

## 与实际效果的差异

| 部位 | 当前实际效果 | 静态目标 |
|---|---|---|
| 深色面板 | 稀疏细线像划痕，轮廓内外光泽差小 | 连续薄水膜与宽幅柔和倒影，干燥哑光区域作对照 |
| 木杆与缠带 | 主要变暗，宽反光容易被抵消 | 反光沿木纹、圆柱曲面与缠带褶皱分布 |
| 手套与袖口 | 同一噪波遮罩难以表现皮革起伏 | 湿光随褶皱变化，凹处仍暗，保留皮革纹理 |

面板首次修订仍有石纹/瓦片感，不能作为目标。最终局部重制改为基本光滑的整张深色金属板，去掉分块、裂缝与亮白斜纹。用户确认的火把/手部保留首版；面板使用单独材质方向，不共用一张噪波高光模板。

生成图的字体、头像或其他细节可能有重绘，不作为游戏素材。已按原始空白底图重新提取，仅替换指定材质，保留正式文本、头像与布局。

## 生产素材与混合

- 使用内置 image_gen，将确认材质映射到原始空白面板和火把精灵；[提示词](assets/prompts.json)、[原始输出](assets/panel-wet-generated.png)、[火把原始输出](assets/torch-wet-generated.png)保留。
- `node scripts/prepare-sailing-wet-artwork.mjs`只做对齐、透明轮廓恢复、裁片与WebP编码，不绘制新的水膜。4张素材共约310KiB，记录见[素材尺寸和内容哈希](assets/prepared-assets.json)。
- 面板仅提取光滑内板，原青铜边框透出，因此没有AI重绘外框之间的叠影。上下片622×137保持原比例，中片622×1262只伸缩平整湿面，不平铺水膜。头像、文字和分隔线仍由原UI绘制。
- 火把/手精灵保持原768×1152画布及逐像素alpha，边缘3px保留原RGB以消除生图环境光晕。运行时湿图与原干图完全同锚点。
- 湿图自身已包含冷暖反光；无需再加人工边缘描线。柔和前沿控制局部到达，184ms推进、18.4ms面板延迟、920ms×3周期、2.2s渐干保持原时序。暂停与减少动态效果保留。
- `SAILING_WET_ARTWORK`统一渲染和群星主题预解码URL，使用内容哈希避开旧缓存。更新素材后将脚本输出revision同步至`src/constants/theme.js`。
- 湿层仍属于scene，文字/HDR火焰/全屏遮罩层级不变。html2canvas死亡快照忽略动态湿层，使用原干图，避免不支持CSS mask导致整层湿图错误。

## 局部飞溅覆盖修订

原第一层遮罩是全表面半透明渐变，前沿走完后整块湿图都会混入。现改为固定的局部透明遮罩与原方向前沿取交集：终态也不能越出这个范围，原湿图、强度、推进及渐干时序保持不变。

- 轮廓使用一个较宽撞击区连接三条长短、弯曲和宽度不同的渐窄分支，从右上向左下延展；噪声仅轻扰边缘，不用椭圆叠云状噪声决定整体形状，也不绘制水珠或新反光。
- `node scripts/generate-sailing-wet-coverage.mjs`离线生成两张带真实alpha的WebP（合计约16KiB），面板三片共用整张遮罩，火把按自身位置单独标定。浏览器不计算噪声。
- 面板有效内板约73.4%完全干燥、24.0%湿区核心、2.5%软边；火把可见轮廓约78.1%完全干燥。统计按原素材有效alpha，避免把火把透明画布误算成干区。脚本断言保留至少45%干区，并保有明显湿区核心。
- `SAILING_WET_COVERAGE`统一遮罩渲染和预解码版本，生成记录见[遮罩数据](assets/coverage-assets.json)。渐干不扩大范围，暂停不移动静态遮罩，减少动态效果也受同一局部限制。
- 截图对照：[干燥](localized-dry.png)、[方向推进中途](localized-front.png)、[前沿完全展开](localized-wet.png)、[844×390手机横屏](localized-mobile.png)。新增gallery“推进中途”，原“半湿对照”继续仅比较混合强度。手机尺寸没有新增滚动条。

## 每波随机飞溅

- 在上述基准形状外增加5种变体，每种分别调整撞击点、24～40度方向角、分支长短/宽度/张开角与边缘噪声。所有变体仍由宽头和3条渐窄分支构成。脚本离线生成并验证覆盖率与各形状的有效材质差异，固定seed可复现。
- 共12张遮罩54,872B；基准图保留原384px字节，新变体宽256px，全部RGBA解码约6.34MiB。面板干区71.37～80.82%，火把干区73.86～85.40%。运行时不计算噪声或生成canvas。
- 每轮每个表面随机抽3种不重复形状，排除当时真实上一张；播放、暂停、普通重渲染及渐干期间不重新抽取。3波仍各920ms，推进184ms和面板延迟18.4ms保持不变。
- mask-image属于离散切换，必须让前两波在换图前归零，再换下一张。退出时保留实际maskImage，与当时的前沿一起渐干；低动态只显示一个轻微湿区。Gallery切入静态对照时终止当前探索并冻结形状，避免强制opacity暴露换图。
- 浏览器连续采样确认三波面板分别使用4、5、2号，火把分别使用4、5、1号：[第一波](random-wave-1.png)、[第二波](random-wave-2.png)、[第三波](random-wave-3.png)。聚焦228项测试覆盖不重复选择、透明换图窗口、中途第二波退出、暂停和低动态；Lint和生产构建通过。

## 局部到达与消退时序

进一步把每个表面分成主撞击区、中部飞沫区和分支末端。每波仍共享一个飞溅轮廓，但3区各自抽取命中、展开、停留和干透时间；中部飞沫用局部扩展，允许早于主方向前沿，随后较早收缩消失。主区保留184ms方向推进，末端不必与其同步。

中部提前命中为概率事件（约65%），其他波可能是主区或末端先到；不是固定的“中部永远第一”次序。小块较薄湿区通常先干，主区保持更久。

- 共6个原生WAAPI，复用原4张湿图与12张覆盖图，没有新增纹理或逐帧JS。每层保持整个表面的素材坐标，圆框比例不变。
- 椭圆所有权E/L取互补分区，3权重和为1；再与共同飞溅轮廓相乘。单层收缩和降低透明度只减少覆盖，不会使多个湿图叠出更亮的接缝。
- `generate-sailing-wet-coverage.mjs`额外输出`src/constants/sailingWetRegions.json`，在真实材质alpha内验证3区均有可见份额，主区过半；原覆盖图hash不变。
- 前两波所有局部均在下一波前干透，避免更换覆盖图时跳形；第三波中部薄水膜更早干透，主区干燥持续1.4～2.2秒。退出时按各区实际进度继续剩余消退，取消未来尚未到达的命中，已干区不复湿。暂停只暂停时钟，不重新随机。
- 真实组件播放采样：[中部先到](local-times-arrival.png)，early opacity 0.513、main/tail为0；[中部先干](local-times-drying.png)，early为0且收缩至0，main 0.515、tail 0.253。不是静态对照强制出的阶段。
- [844×390手机横屏](local-times-mobile.png)滚动尺寸仍为844×390，六个局部正常显示。此为浏览器尺寸验证，不代表手机硬件帧率测试。
- 238项聚焦测试通过，覆盖随机极值、独立先湿先干、透明换形、交界alpha、暂停、第二波中断剩余时长和已干区不复湿；全量Lint和生产构建通过。

## 伪3D飞溅方向校正

之前把接近镜头的屏幕向下运动混同于水花击中较高表面的运动。现将船沿主浪以根部为支点向两侧斜上扬起，镜像后的左右两侧都上扬；根部仍沿原前景alpha接缝移动，末段保留轻微回落。火把前3粒飞沫从较低位置向左上飞，遮挡层级不变。

左侧湿区主轴改为负Y，随机角−24°～−40°，撞击点下移；298°前沿由右下向左上展开。更新12张alpha轮廓和区域锚点，不改已确认的干湿材质。内容版本`b387385a4ddfe441`，共53,058B，解码6.34MiB。所有形状保留至少45%干区，局部独立到达、收缩干燥和暂停/中断机制不变。

生成器验证全部分支末端位于撞击点左上；测试按CSS真实mask尺寸与定位推导前沿采样，确保下部/右侧先湿、上部/左侧后湿，起态全透明、终态不缺角。240项聚焦测试、Lint和生产构建通过。
