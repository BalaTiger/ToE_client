# game/ 重构记录

`src/game/` 已承接大部分纯逻辑。这个文件用于记录仍值得维护的边界，不再保存已经完成的旧迁移清单。

## 当前边界

- `setup.js`：初始化牌堆、玩家和 Debug 强制摸牌。
- `turnEngine.js`：回合开始事件、摸牌、邪神遭遇和回合流转。
- `aiTurn.js`：AI 回合主流程和 AI 行动结算。
- `effectEngine.js`：区域牌、检定牌和部分公共效果结算。
- `animQueueCore.js` / `animQueueHelpers.js`：从状态差异和事件元数据生成动画队列。

## 后续优化点

1. 将仍留在 `App.jsx` 的 UI 阶段处理函数继续拆为小 hook 或小组件。
2. 动画事件顺序尽量沉到 `animQueueHelpers.js` 这类纯函数中，并补测试。
3. 联机同步逻辑继续保持小步抽取，避免改变 ref 读取时机。

## 测试重点

- 回合开始事件与摸牌阶段顺序。
- 蛊惑、检定、送牌、翻牌之间的动画顺序。
- 烛九阴藏牌拦截后继续摸牌的流程。
- 克苏鲁翻面摸牌的剩余摸牌续接。
