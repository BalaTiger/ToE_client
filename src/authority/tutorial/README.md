# v2 本地教学验收

教学只使用本地 `TutorialSession`，独立键 `toe.tutorial.v2`。原叙述来自 `game/tutorialScenario`，只复用其初始章节工厂和文字；不调用旧 App、setGs、applyTutorialStepState 或 clearTutorialWinState。初始化后所有动作经真实 v2 semantic intent。`swap.takeBlind` 永远只提交 `{}`。每次提交等待对应 matchId/revision 的演出与终局动画完成后，才能进入下一段。

## 浏览器完整验收

仅在新 completion QA 的自建标签执行。首页右下「新手教学」总能打开原欢迎弹层；首次点击「踏入黑暗」也会打开。选「✦ 告诉我如何探索」从头开始。解释页按「下一步 →」，行动页只能完成高亮动作。不要用固定秒数连点；以下“等待”均指动画完成、下一段原文字出现，卡牌翻开/飞行、骰子、HP/SAN条、检定与终局演出均不可抢跑。

途中在行动页用原菜单暂停：应出现原暂停画面、无输入/自动动作；继续后恢复。菜单退出并确认后回首页，教学存档保留。重载→「新手教学」→「继续上次教学」，应回当前步骤/已提交后的下一段，不重新亮角色、不重播历史事件；若保存时动作已提交未演完，恢复以当前安全基线完成该步骤，不重复提交。

老手跳过会记完成偏好并打开原身份选择，不提前消耗首次地神局。已完成后仍可首页「新手教学」重练。普通「继续游戏」只读 `toe.offline.v2`。

## 休息和翻面软引导

在正式离线对局，自身 HP<10 且真实 `turn.rest` 可用时，所有现有动画完成后显示原休息说明、高亮HP/休息按钮，并由该引导独占暂停。点击「知道了，继续行动」解除它自己取得的暂停；然后真实点击休息，等骰子、回血、翻面及后续回合演出完成，显示原翻面说明并高亮翻面标记。点「我知道了」继续。

同一浏览器的已读键为 `cthulhu_soft_guides_v1_done`；验收只清自建QA origin的该键。便捷初始存档位于 `test-artifacts/soft-guide-rest.json`：仅QA页面使用为 `toe.offline.v2` 后点击普通「继续游戏」，可直接得到HP7且合法休息的本地局。此fixture不修改生产或其他页面存档。联机/旁观/教学中永不触发软引导；用户本来暂停时不触发，卸载只释放引导自己取得的暂停。

## 正式新局开场

真正新建单机或已观察到同房间 waiting→playing 的玩家会先播原「探索开始」身份动画（2500ms），再由显式初始安全事件播放首回合。普通存档、首次连接已经在playing的房间、重连和旁观只恢复基线。开场事件/队列由主线程负责；本模块只传 `freshStart` / `openingBlocked`，没有快照推导伤害或抽牌。
